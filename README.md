# TinyMayhem

![The front cover of TinyMayhem](assets/Pasted%20image%20-%20Edited.png)
**<a href="github.com/imtua/TinyMayhem"><b>TinyMayhem</b></a>** is a mario-64 type game made by <a href="github.com/imtua/"><b>Imtiaz Ahamed</b></a>. In TinyMayhem, there's a little warrior named Mayhem who has to go through little slimes and collect coins to win the game.

# Game Mechanics
Little warrior has to cross roads while collecting coin. This game is made on godot.

Currently, as now Aug 30, 2026, the game is just the base. No title screen, no end screen, will be added in a few days, that wont be a problem in my sight. I'll post this game in <a href="itch.io/imtua"><b>itch.io</b></a>.
